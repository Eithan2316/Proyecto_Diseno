# Business Sky 🚀

**Business Sky** es una red social interactiva y moderna desarrollada para conectar a emprendedores de todos los tamaños. Permite a los usuarios registrarse, iniciar sesión, crear publicaciones, interactuar mediante "Me gusta", dejar comentarios personalizados y gestionar su propio perfil de emprendedor.

## Características Principales ✨
- **Autenticación completa:** Sistema de registro e inicio de sesión con almacenamiento seguro en el navegador (`localStorage`).
- **Gestión de Perfil Dinámica:** Los datos introducidos al crear una cuenta se transfieren y reflejan automáticamente en el perfil del usuario.
- **Sistema de Publicaciones y Autoría:** Creación de publicaciones por categoría y validación de seguridad (el botón de eliminar solo se muestra y funciona para el creador legítimo de la publicación).
- **Interacción Social (Likes y Comentarios):** Contador de "Me gusta" persistente y sección de comentarios en tiempo real identificados por el usuario activo.
- **Modo Oscuro / Claro Dinámico:** Botón de alternancia de tema integrado con persistencia de preferencias y una interfaz adaptada para garantizar total visibilidad y contraste en ambos modos.
- **Filtrado por Categorías:** Barra de selección rápida para filtrar publicaciones según el sector del emprendimiento.

## Tecnologías Utilizadas 🛠️
- **HTML5:** Estructura semántica del sitio web (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Estilos avanzados mediante variables CSS (`:root`), Flexbox, Grid y diseño totalmente responsivo.
- **JavaScript (Vanilla):** Manipulación dinámica del DOM, gestión de eventos, arreglos, objetos y persistencia de datos con `localStorage`.
- **Git y GitHub:** Control de versiones y despliegue del proyecto.
